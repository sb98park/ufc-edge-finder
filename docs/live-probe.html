Live-mode feasibility probe

Answers one question: can the site's own JavaScript fetch ESPN directly from a visitor's browser? If yes, true live mode is possible — results and the countdown could update on their own during a card instead of waiting for a rebuild. If no, live updating stays capped at the rebuild cadence.

This must be opened from the deployed site's origin (upload it to docs/ and visit octanealpha.com/live-probe.html). Opening it from a local file gives a different, misleading answer — browsers treat file:// as its own origin with its own rules, and curl skips CORS entirely, which is why neither can answer this.
